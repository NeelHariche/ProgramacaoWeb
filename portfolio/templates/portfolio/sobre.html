1. arquitetura mvt do django

A arquitetura MVT (Model-View-Template) é o padrão de design usado pelo Django. É composta por três componentes principais que trabalham em conjunto para processar pedidos e devolver respostas ao utilizador.

MODEL

Define a estrutura dos dados e interage com a base de dados através do ORM Django. Cada classe em models.py representa uma tabela.

VIEW

Recebe o pedido HTTP, consulta os dados necessários através dos modelos e passa esses dados ao template para renderização.

TEMPLATE

Ficheiro HTML com sintaxe Django que recebe os dados da view e os apresenta ao utilizador de forma estruturada e visualmente organizada.

FLUXO DE INFORMAÇÃO

1. Utilizador faz um pedido no browser (ex: /projetos/)
2. Django consulta urls.py e encontra a view correspondente
3. A View vai buscar os dados à base de dados através do Model
4. A View passa os dados ao Template HTML
5. O Template renderiza o HTML final e devolve ao browser
