1. Arquitetura MVT do Django

A arquitetura MVT (Model-View-Template) é o padrão de design usado pelo Django.

  • Model: Define a estrutura dos dados e interage com a base de dados através do ORM Django.
  • View: Recebe o pedido HTTP, consulta os dados e passa-os ao template.
  • Template: Ficheiro HTML que recebe os dados da view e os apresenta ao utilizador.

Fluxo:

  1. Utilizador faz um pedido no browser
  2. Django consulta urls.py e encontra a view correspondente
  3. A View vai buscar os dados através do Model
  4. A View passa os dados ao Template HTML
  5. O Template renderiza o HTML final e devolve ao browser
